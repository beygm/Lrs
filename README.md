# Una carta para ti ♡

Mini sitio romántico de cumpleaños, hecho con HTML, CSS y JavaScript vanilla. Listo para desplegar en Vercel como proyecto estático.

## Verlo en tu computador
Abre `index.html` en el navegador. Para una experiencia más fiel, puedes usar la extensión Live Server de VS Code.

## Personalizar tu carta
Abre `script.js` y cambia el arreglo `LETTER_PARAGRAPHS` por tus párrafos. Cada elemento del arreglo se mostrará como un párrafo separado.

También puedes cambiar:
- El título y los textos de la página en `index.html`.
- Los mensajitos que aparecen al tocar cada flor, en los atributos `data-message` de `index.html`.
- Los colores, fuentes y animaciones en `styles.css`.

## Publicar en Vercel
1. Descomprime el ZIP.
2. Entra a Vercel y elige **Add New → Project**.
3. Importa el repositorio de GitHub donde subiste el contenido de esta carpeta, o usa Vercel CLI.
4. No necesitas framework ni comando de build: es un sitio estático. Deja el directorio raíz como `./`.
5. Deploy.

La imagen de referencia que compartiste está en `assets/lirios-referencia.png` y se usa en la portada.
